# SecureShop 🛡️🛒

Plataforma de comercio electrónico diseñada como proyecto académico y portafolio profesional, construida específicamente para servir como sistema bajo análisis en un ejercicio de **Threat Modeling (OWASP / STRIDE)**.

## Arquitectura y Stack

- **Frontend:** React + TypeScript + Vite + Tailwind CSS
- **Backend:** ASP.NET Core 8 Web API + Entity Framework Core
- **Base de Datos:** MySQL
- **Infraestructura:** Docker Compose
- **Simuladores:** Node.js + Express (Pasarela de pagos y Notificaciones)

## Inicio Rápido

1. Copiar `.env.example` a `.env` y configurar valores locales.
2. Ejecutar `docker-compose up -d db` para levantar la base de datos (por ahora).
3. (Las instrucciones de compilación se actualizarán conforme se integren las fases).
